# Application Python de gestion des tâches

## Présentation
Application simple pour gérer les tâches quotidiennes.

## Fonctionnalités
- Ajouter une tâche.
- Refuser un titre vide.
- Afficher les tâches.
- Rechercher une tâche.
- Quitter le programme.

## Exécution
Ouvrir main.py dans VS Code et cliquer sur Run Python File.
